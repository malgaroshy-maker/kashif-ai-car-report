# 🚗 Flow Cars — تطبيق فحص وتشخيص السيارات (Kashif Mobile)

تطبيق أصيل ومتطور متعدد المنصات (Flutter) مخصص لورش صيانة السيارات وفنيي التشخيص ومشتري السيارات المستعملة في ليبيا. يقوم بتحليل تقارير أجهزة الفحص (OBD-II / Diagnostic Scanners) واستخراج الأعطال وترجمتها فورياً إلى المصطلحات الليبية المعتمدة في ورش الصيانة، مع تقدير أسعار قطع الغيار بالدينار الليبي (LYD) واستخراج أرقام القطع الأصلية (OEM) وتوليد تقارير احترافية (PDF / Standalone HTML) ومشاركتها عبر WhatsApp و QR Code.

## 🌟 أبرز المميزات والإضافات (Core Features)

### 1. ⚙️ محرك أرقام قطع الغيار الشامل (`PartNumberResolver`)
- **توليد أرقام قطع الغيار الأصلية (OEM) الحقيقية:** تم التخلص تماماً من القوائم الثابتة (Hardcoded Lists) والأكواد العشوائية. يعمل النظام عبر الاستعلام السحابي المتصل والتخزين المحلي الذكي (`Hive Cache`).
- **حارس التكرار الصارم (`Deduplication Guard`):** يمنع تكرار نفس كود القطعة لقطع مختلفة في السيارة ويوجه تلقائياً للمطابقة برقم الهيكل (`مطابقة برقم الهيكل (VIN)`).
- **روابط البحث اللحظية المباشرة:** نقرة زر واحدة في بطاقة القطعة تفتح كتالوجات الصانع العالمية المتخصصة (Partsouq, RockAuto, RealOEM, Amayama, Catcar) مسبقة التصفية حسب الموديل وسنة الصنع.
- **بطاقة القطعة التفاعلية (`SparePartCard`):** نسخ رقم الـ OEM للحافظة فوراً، استعراض البدائل التجارية (Bosch, Denso, NGK)، وتقدير الأسعار بالدينار الليبي (LYD).

---

### 2. 🛡️ استقرار فائق وحل الشاشة السوداء لهواتف Poco X7 Pro (HyperOS)
- **إلزام محرك Skia / OpenGL ES:** تم إيقاف محرك Impeller Vulkan الذي كان يسبب شاشة سوداء وتجمداً لـ SurfaceFlinger على معالجات MediaTek Dimensity 8400-Ultra في نظام HyperOS.
- **استرداد تلقائي لقواعد بيانات Hive (`Safe Box Recovery`):** معالجة أي تلف أو تعارض في التخزين المحلي دون إسقاط تشغيل الواجهة.
- **شاشة إقلاع ملكية سريعة (`Splash Branding`):** ظهور شعار كاشف فور لمس الأيقونة بخلفية الكحلي الداكن الفاخر (`#070E1E`).
- **حاصرات أخطاء شاملة:** تغليف الواجهات بـ `ErrorWidget.builder` و `PlatformDispatcher.onError` لمنع أي شاشات رمادية أو تعليق مفاجئ.

---

### 3. 🤖 دعم بوابات الذكاء الاصطناعي المتعددة (APInex & Gemini Integration)
- **بوابة APInex السريعة المجانية (`https://api.apinex.bond/v1`)**:
  - متوافقة مع معيار OpenAI API وتدعم: `gemini-2.5-flash`، `deepseek-chat`، `gpt-4o-mini`، `claude-3-5-sonnet`.
  - تسجيل دخول يومي مجاني على [apinex.bond](https://apinex.bond) للحصول على الحصة.
- **مفتاح Google Gemini المباشر**: دعم مفاتيح Google AI Studio المباشرة (`AIzaSy...`).
- **الخادم السحابي الافتراضي**: يعمل تلقائياً عبر Cloudflare Worker الرسمي لكاشف.
- **نمط توفير التوكنز الفائق (`Ultra Token Saver`)**: ضغط التوجيهات لتسريع الفحص وتقليل استهلاك الحصة.

---

### 4. 🇱🇾 محرك المصطلحات الفنية الليبية المعتمدة (Authentic Libyan Terminology Engine)
- محرك تعريب وتدقيق ذكي وفوري (`ReportSanitizer`) مدعوم بتعابير نمطية وحدود يونيكود عربية `(?<![\u0621-\u064A])` / `(?![\u0621-\u064A])` لضمان عدم حدوث تداخلات أو تشويه للكلمات المشابهة (مثل الحفاظ على "تقرير" أو "استقرار" واستبدال "قير" دائماً بـ "كمبيو").
- تعريب شامل للمصطلحات: **كمبيو**، **بومبة**، **باطنيات**، **سمياص**، **براتشوات**، **مزاطوريات**، **شمعات**، **بوبينات**، **إمبروكم**، **فالب**، **قرسيوني كوبيركو**، **تيرموستاتة**.

---

### 5. 🔌 أدوات الورشة المتقدمة (Specialized Workshop Tools)
- **دليل ومكتشف الفيوزات (`FuseBoxScreen`):** بحث تفاعلي في فيوزات وريليهات السيارة، مواقعها (المحرك / الكابينة)، ورقم الأمبير المناسب مع ترميز الألوان الصناعي.
- **دليل لمبات الطبلون (`DashboardLightsScreen`):** استعراض علامات التحذير ودرجات خطورتها والإجراء الفوري المطلوب.
- **البحث السريع في الأعطال (`DtcLookupScreen`):** إدخال أي كود OBD-II منفرد والحصول على تشخيصه الفوري.
- **قاموس الورشة الليبي (`DictionaryScreen`):** أكثر من 112 مصطلحاً تقنياً مشروحاً ومصنفاً بالعامية الليبية.

---

### 6. 📄 تقارير PDF و HTML تفاعلية متطورة
- **تصدير تقرير PDF بقياس A4 قياسي**: محرك طباعة احترافي مدمج عبر `Printing` و CSS `@media print`، خط **Readex Pro** و **Amiri**، ختم الفحص الإلكتروني وتوقيع الفاحص.
- **تقرير الويب المستقل (Standalone HTML)**: ملف مستقل تماماً يعمل أوفلاين مع الوضع الليلي الكامل.
- **مشاركة سريعة برمز الـ QR ورسائل WhatsApp المنسقة**: كود QR مضغوط وسريع القراءة حتى تحت إضاءة الورش الضعيفة.

## 🚀 تشغيل ومعاينة التطبيق (Live Preview & Development)

### 1. المتطلبات:
- **Flutter SDK**: الإصدار 3.47.6 أو أحدث.
- **Dart SDK**: الإصدار 3.13.0 أو أحدث.

### 2. تشغيل المعاينة المباشرة على سطح المكتب:
```bash
# من جذر المشروع:
run_mobile_preview.bat
```
أو عبر بايثون:
```bash
python preview_launcher.py
```

### 3. تشغيل الاختبارات الآلية (49 اختباراً):
```bash
cd kashif_mobile
flutter test
```

```bash
cd kashif_mobile
flutter analyze
```

## 📦 بناء وتثبيت ملف الـ APK النهائي (Release APK)

### 1. البناء التلقائي لهاتف Poco X7 Pro (ARM64-v8a):
```cmd
# من مجلد kashif_mobile:
build_poco_apk.bat --arm64
```
أو بالضغط على السكريبت الجاهز في جذر المشروع: `بناء_تطبيق_بوكو_Poco_X7_Pro.bat`.

الملف المترجم جاهز في المسار:
```text
APK_OUTPUT\kashif_poco_x7_pro.apk
```

### 2. التثبيت المباشر على الهاتف عبر ADB:
```cmd
build_poco_apk.bat --install
```
أو عبر سكريبت جذر المشروع: `تثبيت_التطبيق_على_الهاتف.bat`.
