# كاشف AI — تطبيق أندرويد (Kashif AI Android App)

تطبيق أندرويد متكامل ومستقل لمنظومة **كاشف AI** لتحليل تقارير وفحص أعطال السيارات بالمصطلحات الدارجة في الورش الليبية، متصل بالخادم السحابي (`https://kashif.malgaroshy.workers.dev`).

---

## المميزات الأساسية (Key Features)

1. **طرق فحص مرنة ومتعددة**:
   - 📸 **تصوير شاشة أجهزة الفحص (Camera OCR)**: التقاط صورة شاشة الماسح (Launch, Autel, ThinkDiag, Ediag) مباشرة بكاميرا الهاتف وتحليلها بالذكاء الاصطناعي.
   - 📄 **رفع تقارير الـ PDF**: استيراد ملفات الفحص الرقمية من ذاكرة الهاتف.
   - ✍️ **إدخال يدوي**: إدخال أكواد الأعطال ورقم الهيكل (VIN) يدوياً.
   - 🏎️ **فحوصات تجريبية سريعة**: تجربة نماذج فحص كاملة بضغطة زر (BMW 528i و Toyota Corolla).

2. **لوحة التقرير التفاعلي (Diagnostic Dashboard)**:
   - مؤشر دائري لصحة وأمان المركبة (0 - 100%).
   - مصفوفة أولويات الصيانة وفق معيار فيوزات الشفرة العالمي (ISO/DIN 72581-3):
     - **10A أحمر (حرج)**: أعطال خطيرة توقف السيارة فوراً.
     - **20A أصفر (متوسط)**: أعطال تؤثر على الأداء والعزم واستهلاك الوقود.
     - **25A رمادي (ذاكرة)**: أكواد سابقة مخزنة.
     - **30A أخضر (سليم)**: الأنظمة السليمة.
   - بطاقات تفصيلية للأعطال تشمل الاسم بالليبي (مثل: بوبينة، امبروكم، حساس الماف، باطنيات)، الأعراض الميكانيكية، الأسباب الجذرية، وخطوات الفحص الكهربائي.
   - دليل قطع الغيار بالأرقام الأصلية (OEM) والأسعار التقديرية بالدينار الليبي (LYD).
   - قائمة فحص الأسطى (Checklist) التفاعلية لمتابعة الفحص خطوة بخطوة في الورشة.

3. **مساعد الأسطى الذكي (AI Mechanic Chat)**:
   - محادثة ذكية متخصصة تفهم وتجيب باللهجة والمصطلحات الليبية.
   - مطلع تلقائياً على بيانات التقرير والسيارة المعروضة.
   - ميزة **الإملاء الصوتي (Speech-to-Text)** للتحدث مباشرة دون الحاجة للكتابة في الورشة.
   - أسئلة سريعة جاهزة للاستفسار عن القطع وأماكن الحساسات وتكلفة الصيانة.

4. **العمل بدون إنترنت (100% Offline Mode)**:
   - **سجل الفحوصات (History)**: حفظ جميع الفحوصات السابقة على الهاتف باستخدام قاعدة بيانات **Hive NoSQL** والرجوع إليها بدون إنترنت.
   - **قاموس الورش (Dictionary)**: 112 مصطلحاً تقنياً معرباً ومفسراً باللهجة الليبية مع محرك بحث لحظي وتصنيفات مفصلة.

5. **المشاركة والتخصيص**:
   - مشاركة بطاقة ملخصة منسقة وجاهزة للإرسال للزبون عبر واتساب بضغطة زر.
   - تخصيص اسم الورشة ورقم الهاتف ليظهر في التقارير.
   - إمكانية إضافة مفتاح Gemini API خاص (اختياري).
   - التبديل بين المظهر النهاري (Daylight Lid) والمظهر الليلي (Night Bay Lid).

## متطلبات التشغيل وبناء التطبيق

- **Flutter SDK**: الإصدار 3.29+ / Dart 3.11+
- **نظام أندرويد المستهدف**: Android 7.0 (API 24) فما فوق

### تشغيل التطبيق في وضع التطوير:
```bash
cd kashif_mobile
flutter run
```

### بناء ملف التثبيت النهائي (Release APK):
```bash
cd kashif_mobile
flutter build apk --release
```
الملف الناتج سيكون في: `kashif_mobile/build/app/outputs/flutter-apk/app-release.apk`

---

## هيكل المشروع (Architecture)

- **إدارة الحالة**: Riverpod (`flutter_riverpod`)
- **الشبكة**: Dio مع Interceptors ومعالجة Multipart للملفات والصور
- **التخزين المحلي**: Hive CE (`hive_flutter`)
- **الهوية البصرية**: Readex Pro (العربية) + Azeret Mono (الأكواد والأرقام)
