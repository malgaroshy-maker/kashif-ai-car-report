# 🚗 Flow Cars — تطبيق فحص وتشخيص السيارات (Kashif Mobile)

تطبيق أصيل ومتطور متعدد المنصات (Flutter) مخصص لورش صيانة السيارات وفنيي التشخيص ومشتري السيارات المستعملة في ليبيا. يقوم بتحليل تقارير أجهزة الفحص (OBD-II / Diagnostic Scanners) واستخراج الأعطال وترجمتها فورياً إلى المصطلحات الليبية المعتمدة في ورش الصيانة، مع تقدير أسعار قطع الغيار بالدينار الليبي (LYD) وتوليد تقارير احترافية (PDF / Standalone HTML) ومشاركتها عبر WhatsApp و QR Code.

---

## 🌟 أبرز المميزات والإضافات الجديدة (Latest Features)

### 1. 🤖 دعم بوابات الذكاء الاصطناعي المتعددة (APInex & Gemini Integration)
- **بوابة APInex السريعة المجانية (`https://api.apinex.bond/v1`)**:
  - متوافقة مع معيار OpenAI API وتدعم مجموعة من أقوى نماذج الذكاء الاصطناعي في العالم:
    - `gemini-2.5-flash` (فائق السرعة والدقة)
    - `deepseek-chat` / `deepseek-reasoner` (تحليل هندسي منطقي متعمق)
    - `gpt-4o-mini` (استقرار عالي)
    - `claude-3-5-sonnet` (فهم سياقي استثنائي)
    - `qwen-2.5-72b`
  - **طريقة الاستخدام**: تسجيل دخول يومي بسيط ومجاني على [apinex.bond](https://apinex.bond) لتفعيل الحصة واستخراج مفتاح الـ API.
  - إمكانية اختبار الاتصال المباشر وفحص الرصيد والحالة بنقرة زر داخل التطبيق.
- **مفتاح Google Gemini المباشر**:
  - إمكانية تشغيل مفتاح Gemini المباشر (`AIzaSy...`) من Google AI Studio مجاناً وبدون أي وسيط.
- **الخادم السحابي الافتراضي**:
  - يعمل افتراضياً عبر الـ Worker الرسمي لمنظومة كاشف (`https://kashif.malgaroshy.workers.dev`).

---

### 2. 🇱🇾 محرك المصطلحات الفنية الليبية المعتمدة (Authentic Libyan Terminology Engine)
- تم بناء محرك تعريب وتدقيق ذكي وفوري (`ReportSanitizer`) مدعوم بتعابير نمطية متقدمة وحدود يونيكود عربية `(?<![\u0621-\u064A])` / `(?![\u0621-\u064A])` لضمان عدم حدوث تداخلات أو تشويه للكلمات المشابهة (مثل الحفاظ على "تقرير" أو "استقرار" واستبدال "قير" دائماً بـ "كمبيو").
- تطبيق تلقائي على مستوى واجهة الذكاء الاصطناعي (System Prompt) ومستوى استيراد وتحليل البيانات (`fromJson`):
  - **كمبيو** (بدلاً من قير أو جير أو ناقل الحركة)
  - **بومبة** (بدلاً من طلمبة أو مضخة)
  - **باطنيات** (بدلاً من عضلات أو نظام التعليق)
  - **سمياص** (بدلاً من عمود الكردان أو الدوران)
  - **براتشوات** (بدلاً من مقاصات أو أذرع التحكم)
  - **مزاطوريات / مزاطوري** (بدلاً من مساعدات أو ممتصات الصدمات)
  - **شمعات** (بدلاً من بواجي أو شمعات الاحتراق)
  - **بوبينات** (بدلاً من كويلات الإشعال)
  - **إمبروكم** (بدلاً من عامود الكامات / الكامة)
  - **فالب** (بدلاً من صمام أو بلف)
  - **قرسيوني كوبيركو** (بدلاً من وجه غطاء البلوف)
  - **تيرموستاتة** (بدلاً من ثرموستات أو بلف الحرارة)

---

### 3. 📄 تقارير PDF و HTML تفاعلية متطورة (Readex Pro Typography)
- **تصدير تقرير PDF بقياس A4 قياسي**:
  - محرك طباعة احترافي مدمج عبر `Printing.convertHtml` و CSS `@media print` يعالج مشكلة الحروف العربية المنفصلة أو المعكوسة.
  - دعم كامل لخط **Readex Pro** الأصلي للطباعة والمطبوعات الرسمية.
  - يشمل بطاقة بيانات السيارة، عداد الكيلومترات، درجة السلامة (Safety Score)، خريطة الأعطال، صور قطع الغيار، وباركود التقرير الرسمي، مع ختم الفحص الإلكتروني وتوقيع الفاحص.
- **تقرير الويب المستقل (Standalone Offline HTML Report)**:
  - ملف HTML واحد مستقل تماماً يعمل دون الحاجة للاتصال بالإنترنت.
  - دعم كامل للوضع الليلي (Dark Mode) بألوان متباينة ومريحة للعين (`#60A5FA` للعناوين، وبطاقات داكنة ذات تباين عالٍ).
  - تصميم أنيق مع شعار دائري، وجداول تفاعلية لخطوات الفحص وأرقام قطع الغيار الأصلية (OEM).

---

### 4. 📲 فحص ومشاركة سريعة برمز الاستجابة (Instant QR Code)
- معمارية ضغط حمولة الباركود (`ReportQrHelper`):
  - حمولة بيانات سريعة ومختصرة (~130 حرفاً) تتضمن رقم الهيكل (VIN)، نتيجة الفحص الإجمالية، ملخص الأعطال الحالية، ورمز تحقق مشفر (CRC/Hash).
  - مستوى تصحيح خطأ متوسط (`QrErrorCorrectLevel.M`) مع هامش هدوء (Quiet Zone) يبلغ 4 وحدات لضمان القراءة اللحظية حتى تحت إضاءة الورش الضعيفة أو شاشات الهواتف ذات السطوع المنخفض.
  - نافذة منبثقة أنيقة ومحسنة مع زر مشاركة مباشر لرسائل WhatsApp منسقة للزبون.

---

### 5. 📸 مسح وتشخيص متقدم متعدد المصادر
- **التعرف البصري بالكاميرا (Camera OCR)**: مسح مباشر لشاشات أجهزة فحص الورش (Launch, Autel, ThinkDiag, Ediag, Topdon).
- **استيراد ملفات الفحص الرقمية (PDF / Text)**: قراءة الترتيب المطبوع لصفحات تقارير الفحص بدقة متناهية.
- **إدخال الأعطال اليدوي**: إمكانية إدخال أكواد الأعطال (DTC) مع رقم الهيكل مباشرة.
- **نماذج تجريبية جاهزة**: فحص تجريبي بضغطة زر لسيارات BMW و Toyota.

---

### 6. 🛠️ وضع العمل دون إنترنت (100% Offline Mode)
- **سجل الفحوصات (History)**: تخزين محلي كامل لجميع الفحوصات والتقارير عبر محرك **Hive NoSQL**.
- **قاموس الورشة الليبي**: قاعدة بيانات تضم أكثر من 112 مصطلحاً تقنياً معرباً ومفسراً باللهجة الليبية مع بحث فوري سريع ومصنف.

## 🏗️ البنية البرمجية والهندسية (Architecture)

```text
kashif_mobile/
├── assets/
│   ├── fonts/               # خطوط Readex Pro (Regular & Bold)
│   ├── images/              # شعار التطبيق وأيقونات الأنظمة
│   └── data/                # قاعدة بيانات المصطلحات الفنية
├── lib/
│   ├── core/
│   │   ├── constants/       # موجهات اللهجة الليبية وقاموس الورش (libyan_dictionary_prompt.dart)
│   │   ├── network/         # عميل Dio وعميل APInex (apinex_client.dart)
│   │   ├── theme/           # نظام ألوان فيوزات السيارة (The Fuse-Box Lid Theme)
│   │   └── utils/           # مولدات التقارير والتدقيق:
│   │       ├── html_generator.dart   # توليد تقارير HTML المستقلة
│   │       ├── pdf_generator.dart    # طباعة A4 PDF عالية الدقة
│   │       ├── report_sanitizer.dart # محرك تدقيق اللهجة الليبية الصارم
│   │       ├── report_qr_helper.dart # تشفير وضغط حمولة الـ QR السريعة
│   │       └── share_service.dart    # مشاركة WhatsApp ومشاركة الملفات
│   ├── data/
│   │   ├── models/          # نماذج بيانات التقرير (مع التطهير التلقائي للمصطلحات)
│   │   │   ├── diagnostic_report.dart
│   │   │   ├── fault_code.dart
│   │   │   ├── spare_part.dart
│   │   │   ├── checklist_step.dart
│   │   │   └── vehicle_info.dart
│   │   └── storage/         # التخزين المحلي باستخدام Hive NoSQL
│   └── presentation/
│       ├── providers/       # إدارة الحالة عبر Riverpod
│       ├── screens/         # شاشات التطبيق الرئيسية:
│       │   ├── home_screen.dart       # الرئيسية وسجل الفحوصات
│       │   ├── scan_screen.dart       # شاشة الفحص والتصوير والـ OCR
│       │   ├── report_screen.dart     # لوحة عرض التقرير والطباعة والـ QR
│       │   ├── chat_screen.dart       # مساعد الأسطى الذكي الصوتي
│       │   ├── dictionary_screen.dart # قاموس مصطلحات الورشة
│       │   └── settings_screen.dart   # إعدادات المفاتيح و APInex ونماذج الذكاء الاصطناعي
│       └── widgets/         # بطاقات الأعطال والفيوزات وشيت الـ QR
└── web/                     # إعدادات المعاينة المباشرة وتخطي الكاش
```

## 🚀 تشغيل ومعاينة التطبيق (Live Preview & Development)

### 1. المتطلبات:
- **Flutter SDK**: الإصدار 3.29.0 أو أحدث.
- **Dart SDK**: الإصدار 3.11.0 أو أحدث.
- **متصفح Google Chrome أو Microsoft Edge**.

### 2. تشغيل المعاينة المباشرة على سطح المكتب (Phone-frame Live Preview):
تم تزويد المشروع ببرنامج تشغيل ذكي باللغة الإنجليزية لتفادي أي مشاكل في ترميز سطر الأوامر (Windows CMD Encoding):
```bash
# من المجلد الرئيسي للمشروع:
run_mobile_preview.bat
```
أو عبر Python مباشرة:
```bash
python preview_launcher.py
```
يقوم هذا السكريبت ببناء نسخة الويب وفتح نافذة متصفح مخصصة تحاكي أبعاد الهاتف الذكي بدقة (390×844) مع تعطيل الـ Cache لضمان ظهور التحديثات فوراً.

### 3. تشغيل التطبيق في وضع التطوير (Debug on Device):
```bash
cd kashif_mobile
flutter run
```

### 4. تشغيل الاختبارات الآلية (Automated Tests):
```bash
cd kashif_mobile
flutter test
```

## 📦 بناء وتثبيت ملف الـ APK النهائي (Release APK)

### 1. بناء حزمة الإصدار (Release Build):
```bash
cd kashif_mobile
flutter build apk --release
```

الملف المترجم جاهز في المسار:
```text
kashif_mobile/build/app/outputs/flutter-apk/app-release.apk
```
(تم نسخ نسخة جاهزة للتثبيت المباشر باسم `flowcars_release.apk` في المجلد الرئيسي).

### 2. التثبيت على الهاتف عبر أداة ADB:
قم بتوصيل الهاتف عبر كابل USB مع تفعيل **تصحيح أخطاء USB (USB Debugging)** ثم نفّذ:
```bash
adb install -r flowcars_release.apk
```

## ⚙️ إعدادات الذكاء الاصطناعي في التطبيق (AI Settings Guide)

1. افتح شاشة **الإعدادات (Settings)** من الشريط السفلي.
2. اختر **مزود الذكاء الاصطناعي (AI Provider)** المفضل لديك:
   - **سيرفر كاشف السحابي**: لا يحتاج أي إعداد، يعمل تلقائياً وبسرعة فائقة.
   - **بوابة APInex السريعة**:
     - قم بزيارة [apinex.bond](https://apinex.bond) وسجّل الدخول مجاناً يومياً للحصول على رصيدك.
     - انسخ مفتاح الـ API من لوحة التحكم وضعه في خانة `APInex API Key`.
     - اختر النموذج المراد استخدامه من القائمة المنسدلة (يوصى بـ `gemini-2.5-flash` للسرعة أو `deepseek-chat` للدقة التحليلية).
     - اضغط على زر **فحص الاتصال** للتأكد من سلامة المفتاح.
   - **مفتاح Google Gemini المباشر**:
     - احصل على مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/app/apikey).
     - ضعه في خانة `مفتاح Gemini API`.
