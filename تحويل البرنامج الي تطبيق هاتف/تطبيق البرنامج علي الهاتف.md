## 📱 نظرة عامة على التطبيق

تم تصميم هذا الدليل والملفات المرفقة لتحويل مشروع **كاشف AI (فاحص تقارير أجهزة كشف أعطال السيارات)** إلى تطبيق أندرويد متكامل يعمل على جميع هواتف أندرويد الذكية بنفس واجهة وتصميم الصورة أعلاه:

1. **أيقونة التطبيق الرسمية (App Icon):**
   - تصميم ثلاثي الأبعاد فاخر باللون الكحلي الداكن مع شعار الترس الذهبي وعلامة التحقق وشبكة التوصيلات الإلكترونية لأجهزة الفحص ووصلة **OBD-II**.
   - العنوان: **كاشف للأعطال وكشف الكمبيوتر**.

2. **واجهة التطبيق من الداخل (Mobile App UI):**
   - **الشريط العلوي (App Bar):** يحتوي على عنوان الشاشة "فحص الرئيسية"، مؤشر الاتصال، وزر التنبيهات والإعدادات.
   - **عداد الفحص الدائري المضيء (Health Gauge):** يوضح نسبة السلامة العامة للسيارة (Overall Health Score)، مع حالة الاتصال (فحص كامل / متصل).
   - **بطاقة فحص الكمبيوتر (OBD-II Scan Card):** وصول سريع لبدء عملية كشف جديدة عبر كاميرا الهاتف، ملف PDF، أو كتابة الأكواد.
   - **شبكة الإجراءات السريعة (Action Grid):**
     - **تقارير الأعطال:** استعراض تفاصيل الأعطال الحرجة والمتوسطة ورموز الـ DTC.
     - **قطع الغيار:** بنك أرقام القطع المطلوبة وتكلفتها التقديرية بالدينار الليبي.
     - **حجز موعد / فحص الورشة:** قائمة فحص الأسطى قبل شراء أو استلام السيارة.
     - **قاموس الورش:** الترجمة الفورية للمصطلحات الإنجليزية إلى دارجة الورش الليبية.
   - **شريط التنقل السفلي (Bottom Navigation):**
     - 🏠 **الرئيسية:** لوحة التحكم والعداد والوصول السريع.
     - 📋 **أعطالي:** تفاصيل التقرير المفحوص والأعطال النشطة.
     - 📍 **الخريطة:** مراكز ومحلات الفحص وقطع الغيار المعتمدة.
     - 👤 **الملف الشخصي:** الإعدادات، مفاتيح الذكاء الاصطناعي، والقاموس.

## 🛠️ طرق تحويل المشروع إلى ملف APK وتثبيته على أجهزة أندرويد

يوجد مساران قياسيان ومعتمدان لتحويل المشروع إلى تطبيق أندرويد جاهز للتثبيت:

### الطريقة الأولى: تحويل المشروع عبر Capacitor (تطبيق Native Android APK) — مُوصى به

تم تضمين ملف الإعداد `capacitor.config.json` في جذر المشروع. لتصدير ملف الـ APK:

#### 1. تثبيت حزم أندرويد الخاصة بـ Capacitor:
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
```

#### 2. تهيئة بيئة أندرويد وإنشاء مجلد التطبيق:
```bash
npx cap add android
```

#### 3. بناء المشروع وتحديث ملفات الأندرويد:
```bash
npm run build
npx cap sync
```

#### 4. فتح المشروع في Android Studio واستخراج الـ APK:
```bash
npx cap open android
```
- داخل **Android Studio**، اضغط على القائمة: **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
- ستحصل مباشرة على ملف `app-debug.apk` جاهز للنقل والتثبيت على أي هاتف أندرويد.

---

### الطريقة الثانية: تصدير ملف APK فوري عبر PWA Builder أو Bubblewrap (TWA)

نظراً لأن المشروع مزود مسبقاً بملف Web Manifest (`src/app/manifest.ts`) وإمكانية التثبيت الفوري (PWA):

#### الخطوة 1: عبر أداة Google Bubblewrap الرسمية:
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest="https://your-domain.com/manifest.webmanifest"
bubblewrap build
```
تنتج هذه الأداة ملف `app-release-signed.apk` مباشرة ومتوافق مع متجر Google Play.

#### الخطوة 2: عبر موقع PWABuilder (دون الحاجة لتثبيت برامج):
1. ارفع المشروع على أي استضافة (مثل Cloudflare Pages أو Vercel).
2. افتح الموقع [PWABuilder.com](https://www.pwabuilder.com/).
3. أدخل رابط موقعك، ثم اضغط **Generate Android App Package**.
4. سيتم تحميل ملف APK جاهز للتثبيت فوراً.

## 💡 المميزات المدمجة في تطبيق الهاتف

| الميزة | الوظيفة على الهاتف |
| :--- | :--- |
| **مسح تقارير الفحص بالكاميرا** | تصوير شاشات أجهزة الفحص (Launch / Autel / G-Scan) وقراءتها فورياً بتقنية التعرف البصري والذكاء الاصطناعي. |
| **قراءة ملفات PDF** | رفع تقارير الفحص الرقمية المستخرجة عبر البلوتوث أو البريد الإلكتروني. |
| **تصنيف الأعطال ومؤشر الصحة** | فرز الأعطال حسب الخطورة (أحمر: خطر، أصفر: متوسط، رمادي: عطل قديم)، وحساب النسبة المئوية في العداد الدائري. |
| **بنك قطع الغيار التفاعلي** | عرض أرقام القطع (Part Numbers) للبحث بها في محلات بيع قطع الغيار والتشليح بليبيا. |
| **قاموس الورش الليبية** | البحث السريع بالدارجة (مثال: طرمبة مية، بوبينة، بوشات، كنترول، فانات...). |
| **العمل بدون اتصال (Offline Cache)** | الوصول إلى التقارير المحفوظة سابقاً وسجل الفحوصات دون الحاجة لإنترنت في الورشة. |
